# Changelog

## [Unreleased]

### Added

- Initial package: all seven EGM skills (brainstorm, draft, review, review-loop, resolve, bootstrap, drift-report), nine Goldfish reviewer personas, five document standards, and execution instructions vendored verbatim from google/elephant-goldfish-model v0.1.0 (Apache-2.0).
- Per-skill Pi pointer to `PI.md`, which maps Goldfish dispatch to the bundled `egm_goldfish` tool, mandates direct dispatch instead of synthesizer nesting, and carries the artifact-directory and question-gate conventions.
- `extensions/goldfish.ts` registering `egm_goldfish`: each reviewer runs in a fresh headless child process (`--no-extensions --no-context-files --no-session --no-mcp --no-skills --no-prompt-templates --exclude-tools edit`), so the zero-context guarantee holds without any subagent extension, discovered skills and templates cannot reach the child, and reviewers cannot modify documents in place. Known residual exposure, documented in PI.md and the README: pi still loads `APPEND_SYSTEM.md` files into the child's system prompt and no flag suppresses them. Optional `model` / `thinking_level` parameters run the child on a chosen pi model pattern and thinking level (independent `--model` / `--thinking` flags; provider-qualified patterns required when a bare name is ambiguous across providers) instead of the pi settings default — the cost lever Codex and Antigravity expose per subagent. Hard-fails on timeout, nonzero exit, signal death, or missing/empty reports; caps three concurrent child sessions with permits released after failures; prunes finished children from the shutdown kill set; rejects non-positive timeouts and already-aborted signals before spawning; kills strays on session shutdown.
- A `tool_call` guard that arms once EGM artifacts have been touched in a session (a read of the bundled skills, personas, standards, or PI.md, an `egm_goldfish` call, or an `/egm-*` command) and stays armed until the session ends, blocking spawn-shaped tools other than `egm_goldfish` so a partially compatible subagent extension cannot silently fork context into a reviewer. Input-based disarming was rejected deliberately: EGM flows are multi-turn and plain answers between stages would drop the guard mid-flow (name-based denylist; residual risk documented in the README).
- `extensions/index.ts` registering one `/egm-<skill>` command per skill, derived from the vendored frontmatter. Commands prefill the editor (fleet pattern; handlers cannot start runs), matching the upstream Antigravity/Claude Code slash UX.
- Skill-line divergence from upstream, sanctioned and recorded: the four reviewer-dispatch paragraphs name `egm_goldfish` where other harnesses name their own spawn tool.
- Structure tests: skill/persona/standards parity with upstream, frontmatter validity, referential integrity of `agents/` and `resources/` references, license markers, Pi pointers, plus `egm_goldfish` unit tests (isolation flags, timeout/empty-report hard failures, abort propagation, concurrency cap).
- Dependency: `@estebanforge/pi-agents-shared ^0.1.0` for the child-process lifecycle (`runProcess`: detached process-group kill, abort, timeout, close-settled output). Publish order when releasing: pi-agents-shared first, then this package.
